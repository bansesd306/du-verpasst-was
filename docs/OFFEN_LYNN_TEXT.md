## 1. Monolog im Bett: „Manchmal fühlt sich ein Moment einfach unendlich an …“ (Z. 2664–2668)
Entscheidung vorerst: **bleibt so.** Patrick: Der Standardgedanke wird in den Sätzen danach weitergedacht, der Monolog ist ein bewusster Bruch (er spricht einmal alles aus), lange Pausen gewollt.
Später nachdenken über:
- **A (sein Text in Ich-Form):** `Es hat sich angefühlt, als würd’s nie aufhören.` / `Obwohl ich wusste, dass es aufhören muss.` / `Vielleicht hab ich das einfach vergessen.` / `…` / `Oder wollte es vergessen.`
- **B (Patrick mag ihn sehr):** `Seit Wochen hab ich Angst, was zu verpassen.` / `Und dann sitz ich zwei Stunden auf einem Balkon` / `und schau kein einziges Mal aufs Handy.` / `… !3` / `Vielleicht verpasst man nur was, wenn man nicht weiß, wo man sein will.`

## 2. „… will ich mich vielleicht doch nicht dran erinnern. Haha.“ (Z. 2674–2675)
Ziel: auflockern, damit der Monolog nicht zu schwer wird. Statt „Haha.“:
- **Innen:** `Verdammte Scheiße, aber wenn’s nichts wird …` / `… !1.5` / `dann hab ich das alles nie gedacht.`
- **Zum Spieler (Patricks Idee):** `Verdammte Scheiße, aber wenn’s nichts wird …` / `… !1.5` / `dann vergesst einfach alles, was ich gerade gesagt hab.`
- **Wichtig (Patrick):** Das „Vergessen“ muss an „wenn’s nichts wird“ hängen. Er lässt das Gefühl zu, in der Hoffnung, dass es stimmt; wird nichts draus, wäre es ihm peinlich. „Okay. Stopp.“ trennt das, fällt weg.
- **ENTSCHIEDEN & EINGEBAUT 24.11. (Patrick): `dann bleibt das unter uns.` mit Pause `!4`.** Varianten waren: `Verdammte Scheiße, aber wenn’s nichts wird …` / `… !1.5` / `dann habt ihr das nie gehört.` oder `dann bleibt das unter uns.`
